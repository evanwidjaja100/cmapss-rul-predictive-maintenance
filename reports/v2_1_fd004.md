# V2.1 FD004 Condition-Aware Experiments

Date: 2026-08-15 · Supersedes `reports/v2_fd004.md` conclusions (V2.1 repair plan R13/R14)

## Problem restated

The V2-11 FD004 experiment (GRU w45 huber, global scaler, `train_FD004.txt`
development) collapsed to a constant prediction (prediction std = 0.0;
official RMSE 64.42 / NASA 2,663,846). Diagnosis: FD004 engines operate
under **5 regimes** (setting_2 drifts in 5 bands x setting_3 in {60, 100};
every engine visits all 5 regimes mid-life in ~49-cycle blocks). A single
global scaler mixes regimes whose sensor distributions differ, so no
sensor pattern is informative after one global standardization.

## Experiment (all variants share: 175 dev / 37 val / 37 cal engines, raw RUL
target, GRU w45 huber, epochs 60, batch 256, patience 8, seed 42, V2.1
fractions manifest `fd004_v2_1_validation_cutoffs.csv`)

| variant | inputs | RMSE | MAE | R2 | NASA total | pred std |
|---|---|---|---|---|---|---|
| A global scaler (V2-11 reproduction) | 21 | 71.93 | 61.30 | -0.23 | 2,554,269.56 | 0.0 |
| B global scaler + settings inputs | 24 | 72.19 | 61.52 | -0.24 | 2,679,350.30 | 0.0 |
| **C regime scalers (KMeans k=6)** | 21 | **29.37** | 20.14 | **0.795** | **46,165.29** | 69.70 |
| D C + settings + one-hot regime | 30 | 27.22 | 17.92 | 0.824 | 68,980.96 | 68.19 |

Results: `experiments/v2_1/fd004_variant_results.csv`,
`experiments/v2_1/fd004_variant_predictions.csv`.

## Findings

1. **A and B collapse** (pred std = 0.0) — the V2-11 negative result is
   reproduced deterministically on the V2.1 manifest. Adding raw settings as
   inputs (B) does not help.
2. **C fixes the collapse**: per-regime sensor scaling (KMeans k=6 on
   settings, per-cluster StandardScaler fit on development-training rows
   only) restores prediction variance (std 69.7), RMSE 71.9 → 29.4,
   R2 −0.23 → 0.795, NASA 2.55M → 46K (55x better).
3. **D** (C + settings + one-hot regime) is RMSE/R2-optimal (27.2 / 0.824)
   but NASA regresses 1.5x (68,981 vs 46,165) — the one-hot regime input
   improves average error while hurting the late-life extremes that dominate
   the NASA score.
4. Selection: **variant C** (NASA-critical), frozen in
   `configs/final_model_v2_1_fd004.yaml`.

## Leakage guarantees

- KMeans, per-regime scalers and the settings scaler fit on the 175
  development engines' training rows only (test: `test_v2_1_fd004_condition.py`);
- regime assignment at inference uses only the fitted KMeans on settings
  (operating conditions, not labels);
- official FD004 is post-hoc by policy (V2-11 inspected the labels).

## Supersedes

The V2-11 conclusion "FD004 GRU collapse; no condition-aware remedy tried"
is superseded: the collapse is fixed by per-regime scaling. The V2-11
prediction-std = 0 collapse remains a valid, reproduced baseline (variant A).
